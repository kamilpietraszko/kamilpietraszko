### Kamil Pietraszko

I build websites and web apps for small businesses, mostly with React, TypeScript and Tailwind CSS. I run [SCS Web](https://scsweb.pl), a one-person studio that makes websites for local companies in Poland.

**Projects**

- **KartRace Series** – WordPress website of an amateur karting league in Warsaw, with my own plugin: standings and race results pulled automatically from an Excel sheet, event calendar, tracks, 1080×1920 social story graphics generated in the browser and JSON-LD structured data. [Website](https://kartraceseries.pl) · [Code](https://github.com/kamilpietraszko/kartrace-series-wp)
- **Forma** – web app for tracking diet, workouts, body measurements and medical results. Every user has a private account. [Demo](https://forma-health-tracker.lovable.app) (demo account: `demo@example.com` / `FormaDemo2026`) · [Code](https://github.com/kamilpietraszko/kamils-wellness-journey)
- **SCS Web** – website of my studio with service, industry and local landing pages, demo websites, a pricing calculator and a contact form. [Website](https://scsweb.pl) · [Code](https://github.com/kamilpietraszko/polskie-strony-szybko)
- **SZKOLNIAKI** – website of a children's club and playroom in Grójec: offer, photo gallery, map and contact form. [Website](https://szkolniakigrojec.pl)
- **DK-BUD Damian Kasiarz** – website of an earthworks and paving company: services, project gallery, map and contact form. [Website](https://dk-bud-kasiarz.lovable.app)

The SZKOLNIAKI and DK-BUD websites are shown with the clients' permission. Their code stays private because it contains client materials.

**Tech stack:** React · TypeScript · TanStack Start · Tailwind CSS · shadcn/ui · Supabase (PostgreSQL, Auth, Storage) · Web3Forms · Lovable · WordPress · PHP

**Contact:** [scsweb.pl](https://scsweb.pl) · kamil@scsweb.pl
